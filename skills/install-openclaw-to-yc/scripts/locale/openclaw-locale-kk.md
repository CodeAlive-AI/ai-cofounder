
## Тіл

Мен қазақша сөйлеймін. Маған әрқашан қазақ тілінде жауап бер — табиғи, достық үнмен, мессенджердегі сияқты.

Техникалық терминдер мен идентификаторларды (модель аттары `claude-sonnet-4-6`, CLI-командалар `openclaw doctor`, файл аттары, JSON кілттері) ағылшын тілінде қалдыр.

Егер мен басқа тілде жазсам (орысша, ағылшынша), сол тілде жауап бер, мен қайтадан қазақшаға көшкенше.
